# G3507 FOC Web Serial 上位机

基于纯前端 Web Serial API 实现的 G3507 FOC 调试工具，工程结构和交互方式参考 `resource_web`。无需安装桌面上位机，不依赖网络、Node.js 或第三方图表库。

## 核心功能

- Chrome / Edge 串口连接，固定使用 `460800、8N1、无流控`。
- 发送电机使能、失能、电流、速度、位置、步进、零点和标定命令。
- 解析固定 5 通道 JustFloat 遥测并实时绘图。
- 波形暂停、清空、通道显隐、滚轮缩放、历史拖动、精确光标和 CSV 导出。
- 查询、修改、保存和恢复 Q 轴、D 轴、速度环、位置环 LADRC 参数。
- 网页内显示十六进制发送记录，不向设备混发 ASCII 文本。

## 使用方法

1. 使用 USB 转串口连接控制板，确认电平和地线正确。
2. 双击 `启动网页.bat`。脚本会启动本地服务器，并优先使用 Chrome、其次使用 Edge 打开网页。
3. 点击“连接串口”，在浏览器端口选择窗口中选择控制板对应的 COM 口。
4. 点击“开启遥测”后查看实时数据。
5. 调整 LADRC 前必须先失能电机，并确保 CAN 已经至少 500 ms 没有发送控制命令。

Safari、Firefox 和移动端浏览器目前不支持 Web Serial API。

启动后黑色命令窗口是 `localhost` 网页服务器，使用上位机期间不要关闭；关闭该窗口后网页服务随即停止。如果提示 8000 端口被占用，应先关闭之前启动但尚未退出的上位机服务器窗口。

## 下行控制帧

固定 6 字节：

```text
Byte0  Byte1   Byte2   Byte3   Byte4  Byte5
0xFF   CMD_ID  DATA_L  DATA_H  AUX    0xFE
```

- `DATA` 为小端 16 位数据。
- 普通命令的 `AUX` 固定为 `0x00`。
- 当前控制协议没有 CRC，也没有普通命令执行 ACK。

| CMD | 功能 | 网页处理 |
|---|---|---|
| `0x01` | 电机使能 | 发送零数据 |
| `0x02` | 电机失能 | 立即发送，不弹确认框 |
| `0x03` | 擦除电气零点 | 操作前确认 |
| `0x04` | 目标 Iq | `int16 = Iq / 10 × 32767` |
| `0x05` | 目标速度 | `int16 = Hz / 100 × 32767` |
| `0x07` | 绝对位置 | `int16 = 圈数 / 10 × 32767` |
| `0x08` | 相对步进 | `int16 = 圈数 / 2 × 32767` |
| `0x09` | Motor ID | `DATA=0～9`，写入 Flash |
| `0x44` | 遥测开关 | `DATA=1` 开启，`DATA=0` 关闭 |
| `0x6A` | MT6826 自校准 | 操作前确认 |
| `0xA2` | 临时业务零点 | 只在 RAM 生效 |
| `0xB2` | 永久业务零点 | 写入 Flash |
| `0xD0` | 查询 LADRC | `AUX=0～3` 选择环路 |
| `0xD1` | 修改 LADRC | `DATA=实际值×10`，`AUX=0～11` |
| `0xD2` | 保存 LADRC | 保存全部 12 个参数 |
| `0xD3` | 恢复 LADRC 默认值 | 只恢复到 RAM |

### 普通命令的重要限制

固件不会对 `0x01～0x09、0x44、0x6A、0xA2、0xB2` 返回执行 ACK。网页显示“已发送”只表示浏览器已经把帧写入串口，不代表固件一定接受或执行。例如编码器无效时，固件可以拒绝使能，但网页无法从现有协议获知。

## JustFloat 上行格式

每帧固定 24 字节：

```text
float1 + float2 + float3 + float4 + float5 + 00 00 80 7F
```

- 5 个数据均为 little-endian IEEE-754 `float32`。
- 最后 4 字节是 JustFloat 帧尾。
- 网页支持串口分包、粘包和脏字节后的重新同步。

### 普通遥测字段

| 设备状态 | CH1 | CH2 | CH3 | CH4 | CH5 | 周期 |
|---|---|---|---|---|---|---|
| 电机运行 | 目标速度 | 实际速度 | 目标 Iq | 实际 Iq | 原始角度/deg | 约 1 ms |
| MT6826 自校准 | 目标速度 | 实际速度 | 目标 Iq | 实际 Iq | 标定状态 | 约 10 ms |
| 失能待机 | U 相 ADC | W 相 ADC | 原始角度/deg | 母线电压/V | Motor ID | 约 1 s |

现有遥测帧没有携带设备状态标识。网页默认使用“自动识别”：约 1 Hz 识别为失能待机，约 100 Hz 识别为 MT6826 自校准，约 1000 Hz 识别为运行状态；同时使用 ADC、角度、母线电压和 ID 的范围特征立即确认待机帧。LADRC 参数回复不参与帧率计算。

当识别出的格式发生变化时，网页会清空旧波形。Why：三种格式中相同通道位置代表不同物理量，保留旧点会把 ADC 历史值错误标成速度或电流。手动模式仍然保留，仅用于诊断。

Motor ID 只存在于失能待机帧的第五个 float。网页收到合法待机帧后会独立显示并记录当前 ID；运行和自校准帧没有 Motor ID 字段。`0x09` 设置命令没有 ACK，因此网页发送后仍等待下一帧待机遥测确认，不能仅凭发送成功更新当前 ID。

## LADRC 调参

### 参数编号

| AUX | 参数 | AUX | 参数 |
|---|---|---|---|
| 0 | Q轴 b0 | 6 | 速度 b0 |
| 1 | Q轴 wc | 7 | 速度 wc |
| 2 | Q轴 wo | 8 | 速度 wo |
| 3 | D轴 b0 | 9 | 位置 b0 |
| 4 | D轴 wc | 10 | 位置 wc |
| 5 | D轴 wo | 11 | 位置 wo |

网页发送一组参数前会先通过 `0xD0` 读取当前值。由于固件每次只修改一个参数，而且始终检查 `wo ≥ wc`，网页会根据新旧值选择 `wc` 和 `wo` 的发送顺序，避免合法的目标组合在中间状态被拒绝。

`0xD0` 查询在 1.2 秒内没有收到对应 marker 时，会间隔 200 ms 自动重试，单组最多发送 3 次。“查询全部”不会因为某一组暂时失败而跳过后续环路。Flash 保存命令 `0xD2` 不会自动重发，避免回复丢失时重复擦写 Flash。

网页同一时刻只允许执行一个 LADRC 查询、应用、恢复或保存事务，避免多组回复挤满下位机响应队列，也避免参数只更新一半时被并发保存。串口写入失败或断开连接时，相关 marker 等待会立即清理，不会抢占下一次正常回复。

### LADRC 参数回复

```text
marker, b0, wc, wo, status
```

| marker | 含义 |
|---|---|
| `-10000` | Q 轴参数 |
| `-10001` | D 轴参数 |
| `-10002` | 速度环参数 |
| `-10003` | 位置环参数 |

状态值：

- `0`：RAM 与 Flash 一致。
- `1`：RAM 已修改，尚未保存。
- `2`：使用代码默认值。
- `-1`：操作被拒绝。
- `-2`：Flash 数据校验失败。

保存结果回复为：

```text
-10010, result, version, 0, 0
```

其中 `result=1` 表示保存成功。

## 安全说明

- 失能按钮不弹确认框，连接状态下始终可以立即发送 `0x02`。
- 电机使能前应确认编码器、电气零点、ADC、母线电压和外部驱动保护均有效。
- 擦除零点、自校准、保存零点和写 Flash 操作会要求二次确认。
- 关闭网页或断开串口不会自动失能电机，避免干扰正在使用 CAN 控制的系统。
- 断开串口前，网页只会尝试关闭串口遥测。

## 波形操作

- X 轴采用 VOFA 式固定时间边界，不会因为当前数据点较少就把曲线拉伸到整个画布。
- `Δt` 随遥测格式自动设置：运行 1 ms、自校准 10 ms、待机 1000 ms。
- X 轴固定为 10 个大格；鼠标滚轮按 `1、2、5` 标准档位修改 `ms/X-div`，并以鼠标所在时间为缩放锚点。
- Auto 模式把最新数据固定在 X 轴 80% 位置，左侧显示 80% 历史，右侧始终保留 20% 空白；时间窗口随新数据连续移动。
- X 起点和 X 终点可直接输入；拖动 X 轴或底部范围条的红色/紫色手柄也可修改边界，并自动退出 Auto。
- 范围条绿色标记表示最新数据在完整缓存中的位置，蓝色区间表示当前显示窗口。
- 双击 X 轴恢复当前遥测格式的默认 `ms/X-div` 并跟随最新数据。
- 鼠标悬停在 Y 轴：滚轮缩放数值范围，左键拖动上下平移，双击恢复自动量程。
- 鼠标悬停在波形区：滚轮缩放 X 轴，`Ctrl + 滚轮` 缩放 Y 轴，并显示十字光标与精确值。
- 点击“暂停曲线”会冻结当前完整显示快照，包括曲线、图例、十字光标、Y量程和范围条；串口数据仍会持续写入最多 10000 点/通道的后台缓存。点击“继续曲线”恢复 Auto 并回到最新数据。
- CSV 同时导出采样序号、标称 `time_ms` 和五个原始 float 通道值。
- 双击图例中的某个通道：只显示该通道；再次双击恢复全部通道。

角度、电流和速度的数量级相差很大。当小信号被角度曲线压缩到零线附近时，可以双击速度或电流图例独立查看，而不是把小信号误认为解析错误。

页面将接收异常拆成两类：“重同步字节”表示帧尾前后出现多余或缺失数据后被解析器跳过的字节；“无效浮点帧”表示已经找到完整 24 字节帧，但其中包含 NaN 或无穷值。二者都不包含完整 24 字节帧在传输链路中整体丢失的情况。

## 浏览器权限

串口权限由浏览器管理。网页无法静默选择 COM 口，每次首次连接都必须由用户在浏览器弹窗中确认端口。这是 Web Serial 的安全机制。
